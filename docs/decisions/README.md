- 파일명은 `NNNN-짧은-영문-슬러그.md`, 번호는 이어서 붙입니다.
- 결정을 뒤집을 때는 기존 기록을 지우지 않고, 새 기록을 만든 뒤 기존 기록의 상태를
  "대체됨 (NNNN)"으로 바꿉니다. 왜 바뀌었는지가 그대로 남습니다.
